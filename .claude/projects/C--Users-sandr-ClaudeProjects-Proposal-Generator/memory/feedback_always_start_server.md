Always start the dev server (`npm run dev`) myself. Never ask the user to start it or suggest they type `! npm run dev`.

**Why:** User considers it my responsibility to keep the dev environment running and current.

**How to apply:** Before telling the user to test something at localhost, always start/restart the dev server first via Bash tool.
